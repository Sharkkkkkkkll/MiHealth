# MiHealth 睡眠智能体系统

一个「数据驱动 + AI 决策 + 系统级执行」的睡眠智能体系统：自动学习你的睡眠规律，规划今晚几点睡，并在起床窗口内挑浅睡期把你叫醒。

## 项目简介

MiHealth 通过小米手环采集健康数据，结合历史睡眠分期和实时心率，实现：

- AI 睡眠规划：基于 90 天真实数据学习个人入睡/起床规律
- 睡前提醒：固定五弹 + AI 文案
- 智能闹钟：在浅睡/REM 期叫醒，深睡保护，保底兜底
- BLE 直连：直接读取手环实时心率，锁屏整晚保活
- 多账号隔离：数据、记忆、AI 决策按用户隔离
- 反馈闭环：唤醒后复盘，Agent 持续进化

## 系统架构

```
小米手环 → 小米运动健康 App → 云端 → 米桥拉取
                                        ↓ JSON 导出
                              仪表盘服务器 (:8000)
                                        ↓ HTTP /api/*
                              代理服务器 (:8001)
                                        ↓ HTTP /api/agent/*
                              Android 应用程序（Kotlin/Compose）
                                        ↓ BLE 直连
                                     小米手环
```

## 核心功能

### AI 睡眠规划

- S/P 双锚点模型：生理困意 + 起床倒推
- LLM 判断今晚情景（正常/负债/质量差/硬事夜）
- 规则引擎兜底，LLM 失败也能给出合理推荐
- 白天小睡、参数变化、新的一天自动触发重新规划

### 智能闹钟

- 起床窗口内实时监测心率，检测浅睡/REM 信号
- 窗口开始前绝不叫
- 深睡保护：窗口内无浅睡时不打断深睡
- 渐进式响铃：每 5 秒升一档，30 秒确认醒来
- 未醒则疯狂震动 + 最大音量
- 保底闹钟系统级保证，App 被杀也能响

### BLE 心率直连

- 标准 GATT 协议直连手环心率服务（0x180D/0x2A37）
- `autoConnect=true` + 指数退避重连
- 前台服务 + WakeLock + WifiLock 锁屏保活
- 心率广播开关开着就全量记录，AI 后续自己取窗口段

### 多账号隔离

- 每台手机扫码登录各自小米账号
- 数据、记忆、AI 决策、LLM 日志全部按 `user_id` 隔离
- 两个账号同时拉取互不阻塞
- 每个人的 AI 都基于自己的数据学习和进化

## 技术栈

| 层 | 技术 |
|---|---|
| Android | Kotlin + Jetpack Compose |
| 代理服务 | Python 3.14 + 标准库 http.server，无任何第三方依赖 |
| LLM | 百炼 qwen3.x（OpenAI 兼容接口），规则引擎兜底 |
| 数据桥 | Mi Fitness Data Bridge |
| 实时心率 | Android BLE GATT |
| 本地存储 | SharedPreferences + JSON 文件 |
| 服务器存储 | JSON 文件 + SQLite |

## Agent 智能体设计

这是本项目的核心。Agent 不是简单的接口封装，而是一个有记忆、会决策、能执行、会复盘进化的智能体。

### 模块结构

```
代理/
├── agent_server.py      # HTTP 服务 + 调度线程 + 启动恢复
├── planner.py           # 睡眠规划（S/P 双锚点 + LLM 决策）
├── notifier.py          # 睡前提醒 + 闹钟包生成
├── coach.py             # 事件状态机（P/STAY/HR/OD）
├── wake_engine.py       # 智能闹钟策略生成 + 复盘
├── memory.py            # 三层记忆（preferences/history/feedback/tolerance）
├── pattern.py           # 睡眠模式学习（圆周统计）
├── data_source.py       # 数据读取 + 质量系数 + 静息 HR
├── config.py            # 配置 + 多用户目录
├── windows.py           # 窗口判断
├── rules.py             # 规则引擎
└── brain.py             # LLM 封装
```

### 决策链路

```
数据采集 → 睡眠模式学习 → 规则引擎算候选 → LLM 判断情景
  → 生成今晚计划 → 生成闹钟包 → 手机执行
  → 唤醒后复盘 → 更新记忆 → 下次更准
```

### 三层记忆

Agent 使用`memory.py` 维护三层记忆，全部按用户隔离：

- **偏好设置**：作息目标、授权开关、闹钟包、唤醒策略
**：Agent 对话和决策滚动记录
- **反馈**：唤醒复盘、用户反馈，用于学习进化

### 规则引擎 + LLM 分层

Agent 采用「规则引擎打底 + LLM 决策」的双层结构：

- **规则引擎**：负责算候选值、判断时机、越界校验、幂等保护
- **LLM**：负责判断今晚情景（正常/负债/质量差/硬事夜），输出分层建议
- **LLM 失败**：自动退回规则中心值，保证系统可靠

### 多用户隔离

每个用户有独立的：

- `memory_data/<user_id>/`：记忆目录
- `JSON/<user_id>/`：数据目录
- `mi_fitness_local_<uid>.db`：数据库
- `usage_log.jsonl`：LLM 用量日志

所有接口带 `user_id`，后台线程显式传用户，不会串数据。

## 快速开始

### 1. 启动服务器

```bash
# 启动仪表盘服务器
python start_server.py

# 启动 Agent 服务器（另开一个终端）
python Agent/agent_server.py
```

### 2. 安装 App

1. 用 Android Studio 构建 APK
2. 安装到 Android 8.0+ 手机
3. 打开 App，填写电脑局域网 IP

### 3. 扫码登录

1. 打开 App → 设置 → 小米账号登录
2. 用米家 App 扫码
3. 扫码成功后自动保存账号

### 4. 开启心率广播

1. 先在小米运动健康里打开手环的「心率广播」
2. 打开 MiHealth → 更多 → 心率广播
3. 扫描并选择手环设备
4. 连接成功后锁屏也会自动保活记录
