# MiHealth 睡眠智能体系统 · 产品亮点

> 版本：v1.0
> 日期：2026-10-20
> 作者：Sharkkkkkkkll

## 一句话介绍

**MiHealth 是一个「数据驱动 + AI 决策 + 系统级执行」的睡眠智能体系统：自动学习你的睡眠规律，规划今晚几点睡，并在起床窗口内挑浅睡期把你叫醒。**

## 核心亮点

### 1. 端到端 AI Agent 闭环

```
数据采集 → 睡眠模式学习 → AI 规划 → 睡前提醒 → 智能叫醒 → 反馈复盘 → 记忆进化
```

不是「查数据的 App」，而是一个会自己学习、自己决策、自己执行、自己复盘进化的智能体。

### 2. 不拍脑袋的 AI 睡眠规划

- 基于 90 天真实睡眠数据学习个人入睡/起床规律
- S/P 双锚点模型：生理困意 + 起床倒推
- LLM 判断今晚情景（正常/负债/质量差/硬事夜）
- 规则引擎兜底，LLM 失败也能给出合理推荐

### 3. 在浅睡期叫醒你

- 起床窗口内实时监测心率，检测浅睡/REM 信号
- 窗口开始前绝不叫，深睡保护不打断深睡
- 渐进式响铃，每 5 秒升一档，30 秒确认醒来
- 未醒则疯狂震动 + 最大音量
- 保底闹钟系统级保证，App 被杀也能响

### 4. BLE 直连手环，锁屏整晚保活

- 不依赖第三方心率 App
- 标准 GATT 协议直连手环心率服务
- `autoConnect=true` + 指数退避重连
- 前台服务 + WakeLock + WifiLock 锁屏保活
- 实测锁屏整晚心率不断

### 5. 多账号数据隔离

- 每台手机扫码登录各自小米账号
- 数据、记忆、AI 决策、LLM 日志全部按 `user_id` 隔离
- 两个账号同时拉取互不阻塞
- 每个人的 AI 都基于自己的数据学习和进化

### 6. 系统级可靠性

- 闹钟走系统 `setAlarmClock`，App 被杀也响
- 保底闹钟设置起床时间时就排好，每天重复
- 正常叫醒后自动取消保底，防双响
- Agent 启动自动恢复计划/闹钟包/文案
- 幂等保护：不重复生成、不重复重建

### 7. 反馈闭环持续进化

- 唤醒后上传完整心率曲线复盘
- Agent 比对预测 vs 实际，更新记忆
- 每次叫醒都让下一次更准

## 技术亮点

| 领域 | 亮点 |
|---|---|
| AI Agent | 记忆/决策/工具/反馈闭环 |
| 算法 | 圆周统计、S/P 双锚点、浅睡识别、深睡保护 |
| Android | Compose、BLE GATT、前台服务、系统闹钟 |
| 可靠性 | 幂等保护、启动恢复、指数退避重连 |
| 多用户 | `threading.local()` 并发隔离、按用户目录隔离 |
| 成本 | 事件驱动，LLM 调用最小化 |

## 适合谁

- 作息不规律、想改善睡眠质量的用户
- 不想被闹钟强行打断深睡的用户
- 需要「在合适的时间被叫醒」的用户
- 对 AI Agent / 智能硬件感兴趣的开发者
