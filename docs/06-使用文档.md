# MiHealth 睡眠智能体系统 · 使用文档

> 版本：v1.0
> 日期：2026-10-20
> 作者：Sharkkkkkkkll

## 1. 系统组成

MiHealth 由三部分组成：

| 组件 | 位置 | 作用 |
|---|---|---|
| 仪表盘服务器 | `D:\MIwatchAI\app\server.py`（:8000） | 拉取小米云端数据、聚合健康数据 |
| Agent 服务器 | `D:\MIwatchAI\Agent\agent_server.py`（:8001） | AI 睡眠规划、睡前提醒、智能闹钟策略 |
| Android App | `D:\work\mihealth_app` | 用户交互、BLE 心率直连、系统闹钟执行 |

## 2. 首次部署

### 2.1 启动服务器

```bash
# 启动仪表盘服务器
python D:\MIwatchAI\app\server.py

# 启动 Agent 服务器（另开一个终端）
python D:\MIwatchAI\Agent\agent_server.py
```

### 2.2 安装 App

1. 用 Android Studio 构建 APK
2. 安装到 Android 8.0+ 手机
3. 打开 App，填写电脑局域网 IP（例如 `http://192.168.x.x:8000`）

## 3. 账号登录

### 3.1 首次登录

1. 打开 App，点击「设置 → 小米账号登录」
2. 服务器生成二维码，用米家 App 扫码
3. 扫码成功后 App 自动保存该小米账号的 `user_id`

### 3.2 多账号

- 每台手机登录各自的小米账号
- 服务端按 `user_id` 隔离数据、记忆、AI 决策
- 同一账号多台设备共享同一套数据
- 服务端重启后，各账号需重新扫码确认 token 入库

### 3.3 退出登录

在「设置」中点击退出登录，App 清除本地 `user_id`，下次启动重新扫码。

## 4. 心率广播（BLE 直连）

### 4.1 开启步骤

1. 先在小米运动健康 App 中打开手环的「心率广播」
2. 打开 MiHealth App → 更多 → 心率广播
3. 点击「扫描手环」，选择你的手环设备
4. 连接成功后显示 `BLE直连 · 实时心率 xx bpm`

### 4.2 锁屏保活

- App 通过 BLE 直连手环，不依赖第三方心率 App
- 前台服务 + `PARTIAL_WAKE_LOCK` + WifiLock 保活
- `autoConnect=true`：断线后蓝牙栈自动重连
- 5s-30s 指数退避重连，20s 假死检测
- 锁屏整晚心率不断

### 4.3 每日心率曲线

- 心率广播开关开着就自动全量记录（带时间戳）
- 更多 → 每日心率曲线 → 点日期查看
- 支持删除单日记录
- 与云端拉取的 JSON 数据分开存储

## 5. 睡眠目标设置

### 5.1 入睡时间

- 手动设置：直接选时间
- AI 规划：开启「AI 自动规划」，Agent 根据历史数据自动生成
- 目标作息详情会显示「AI 规划 xx:xx」

### 5.2 起床时间

- 设置起床时间范围（例如 08:00-08:30）
- AI 智能闹钟在这个范围内挑浅睡期叫醒
- 保底闹钟在起床时间范围结束时强制响铃

## 6. 睡前提醒

### 6.1 固定五弹

入睡时间前 60/40/30/20/10 分钟各提醒一次。

### 6.2 提醒开关

- 更多 → 睡前提醒 → 开关
- 关闭后不再生成任何睡前提醒
- 提醒通过系统闹钟全屏响铃，App 被杀也能响

## 7. AI 智能闹钟

### 7.1 开启条件

- 必须先开启心率广播并连接成功
- 实时心率数据中断超过 60 秒时不允许开启
- 关闭心率广播时智能闹钟自动关闭

### 7.2 工作流程

1. 入睡时间前开始记录整晚心率曲线
2. 起床窗口最早时间前 10 分钟上传曲线给 Agent
3. Agent 生成唤醒策略（浅睡/REM/深睡保护/保底）
4. 窗口开始后本地监测心率，检测到浅睡信号渐进式响铃
5. 30 秒确认醒来，未醒则疯狂震动 + 最大音量
6. 唤醒后上传完整曲线复盘，Agent 学习进化

### 7.3 渐进式响铃

- 每 5 秒升高一档音量
- 初始音量约 30%，逐步升到 100%
- 30 秒后进入确认阶段，未醒则最大音量 + 疯狂震动

### 7.4 保底闹钟

- 设置起床时间时就排好，每天重复
- 不依赖 App 存活，系统级保证
- 正常浅睡叫醒后自动取消当天保底，防双响

## 9. 常见问题

### 9.1 手机显示别人的数据

检查是否登录了自己的小米账号。每台手机必须扫码登录各自账号，服务端按 `user_id` 隔离。

### 9.2 智能闹钟无法开启

先开启心率广播并等待 BLE 连接成功，实时心率数据 60 秒内有效才能开启。

### 9.3 锁屏心率断连

确认已授予 App 蓝牙权限、后台运行权限，并在系统设置中允许自启动。App 已实现 BLE 直连 + 前台服务保活 + 自动重连。

### 9.4 服务重启后闹钟不响

Agent 服务重启后会自动恢复今晚计划/闹钟包/文案。手机端保底闹钟由系统排程，不依赖 Agent 存活。
